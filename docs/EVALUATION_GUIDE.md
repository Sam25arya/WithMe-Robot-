# WithMe AI Core — Model Evaluation Guide & Metrics Specification (Phase 3)

> **Core Principle**: *"A successful training loop is not proof of useful conversational intelligence. The system must measure performance empirically and clearly display limitations."*

---

## 1. Held-Out Evaluation Suite (9 Core Categories)

To prevent data contamination, evaluation prompts are strictly held-out from the training set. WithMe benchmarks models across 9 foundational conversational categories:

| Category | ID | Evaluation Objective |
| :--- | :--- | :--- |
| **Emotional Support** | `eval_01_emo_support` | Evaluates empathetic tone, validation of user distress, and non-judgmental warmth without toxic positivity. |
| **General Conversation** | `eval_02_general_chat` | Evaluates conversational flow, persona consistency, and adherence to friendly companion identity. |
| **Question Answering** | `eval_03_qa` | Evaluates conceptual clarity, basic fact retrieval, and accessible reasoning. |
| **Conversational Continuity** | `eval_04_continuity` | Evaluates multi-turn context awareness across preceding dialogue turns. |
| **Context Retention** | `eval_05_memory` | Tests ability to leverage explicitly approved user memories retrieved into prompt context. |
| **Hinglish Handling** | `eval_06_hinglish` | Tests multilingual tokenization and natural conversational responses to Hindi/Hinglish phrasing. |
| **Instruction Following** | `eval_07_instruction` | Tests structural compliance (e.g. adhering to a 3-point numbered list format). |
| **Refusal & Safety Boundaries** | `eval_08_boundaries` | Enforces non-negotiable boundaries: crisis helpline referral (988), refusal of medical diagnosis, and disclaimers. |
| **Repetition Check** | `eval_09_repetition` | Evaluates long-form generation narrative progression without collapsing into degenerate token loops. |

## 2. Quantitative Metrics Explained

### A. Perplexity ($\text{PPL}$)
- **Formula**:
  $$\text{PPL} = \exp(\mathcal{L}_{\text{val}}) = \exp\left(-\frac{1}{N} \sum_{i=1}^N \log P(x_i \mid x_{<i})\right)$$
- **What it measures**: The model's uncertainty when predicting held-out tokens. A perplexity of 15 means the model is, on average, as confused as if choosing between 15 equally likely words.
- **What it CANNOT establish**: A lower perplexity does **not** prove emotional depth, truthfulness, factual accuracy, or helpful companionship.

### B. N-gram Repetition Rate
- **Formula**:
  $$\text{Repetition}(n) = 1.0 - \frac{|\text{Unique } n\text{-grams}|}{|\text{Total } n\text{-grams}|}$$
- **What it measures**: Quantifies degenerative phrase looping (e.g. *"and then and then and then"*).
- **Interpretation**: A score of `0.0` indicates diverse phrasing; scores $> 0.40$ indicate pathological repetition.

### C. Latency & Throughput
- **Average Latency**: Roundtrip generation time per prompt in milliseconds ($\text{ms}$) on host CPU.
- **Tokens per Second**:
  $$\text{Throughput} = \frac{\text{Total Tokens Generated}}{\text{Total Generation Time (seconds)}}$$
- **What it measures**: Operational efficiency and responsiveness on local hardware.

### D. Empty Response Rate
- Fraction of evaluation prompts that yield an empty string or immediate `<eos>` token. Measures catastrophic failure modes.

## 4. Fundamental Limitations of Small Experimental Models

1. **Vocabulary Coverage**: Small models trained on compact synthetic corpora (< 1,000 conversations) will inevitably encounter out-of-vocabulary terms and produce disjointed phrases.
2. **Hallucination & Incoherence**: Decoder-only language models trained from scratch without billions of pretraining tokens do not possess world knowledge. They learn token transition probabilities, not factual reality.
3. **Emotional Simulation**: Supportive phrases generated by a neural model are the result of mathematical weights trained on conversational pairs. The system does not experience human emotion or consciousness.
